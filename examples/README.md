# Examples for unversioned, machine-local files

These show the structure of files that are deliberately **not** in this repo (work identities,
corporate certs, installer-managed shell lines). Copy and edit them on each new machine:

- `gitconfig-local.example` -> `~/.gitconfig-local`
- `gitconfig-identity.example` -> e.g. `~/Documents/Work/.gitconfig-work`
- `zshrc.local.example` -> `~/.zshrc.local`
- `../helix/.config/helix/snow-run.env.example` -> `~/.config/snow-run/env`
